SAFE SPACE THERAPY — UPDATED STARTER WEBSITE

Files:
- index.html: responsive website with fixed anchor navigation, mood-based affirmation selection, search/category filtering, local favorites, local journal entries, and a booking enquiry form placeholder.
- affirmations.json: editable starter/reference library for categories and affirmations.

HOW TO PUBLISH ON NETLIFY
1. Extract this ZIP on your phone/computer.
2. Open Netlify and your existing Safe Space Therapy site.
3. Deploy the extracted site folder (the folder containing index.html) using Netlify's manual deploy / deploy upload flow.
4. Open the live URL and test the menu, moods, search, favorites, journal and booking form.

BEFORE LAUNCH
- In index.html, replace const BOOKING_EMAIL='support@safe-spacetherapy.com' with the therapist's approved booking email. The booking form is a starter email enquiry, not a connected booking calendar and does not confirm appointments.
- Services and pricing cards have been added from the supplied content pack. Confirm the listed fees and service details before launch. Add the therapist's approved bio, qualifications, approach and languages.
- Google Analytics 4 is not active yet. Create a GA4 property and add the official Google tag / Measurement ID before publishing; respect applicable privacy and cookie requirements.
- Favorites and journal entries use localStorage on the current browser/device only. They are not synced to an account or cloud. Do not store sensitive therapy records in this starter version.
- The Login / Sign Up feature from the earlier visual concept has not been added because it requires an authentication service and secure backend.

This is a front-end starter website, not a clinical service or emergency service.
